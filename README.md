# 🔔 Pass : Java 미니 프로젝트 모음 🔔

Java 문법과 객체 지향 프로그래밍(OOP) 개념을 학습하며 구현한 콘솔 기반 미니 프로그램 모음입니다. 각 프로젝트는 `src` 폴더 내 개별 패키지에 구현되어 있으며, 각 항목의 제목 링크를 클릭하면 해당 소스코드 폴더로 바로 이동할 수 있습니다[cite: 2].

## 🗂️ 프로젝트 목록

각 패키지에 대한 자세한 설명과 실행 방법은 이동된 폴더 내의 `README.md` 파일에서 확인하실 수 있습니다.

### 1. [🥤음료 자판기 (p01)](src/p01)
*   **개요**: 금액 투입 후 원하는 음료를 번호로 선택하면 구매 내역과 거스름돈을 계산하여 출력하는 프로그램입니다.
*   **학습 개념**: 상속, 추상 클래스(`abstract`), 컬렉션(`ArrayList`)

### 2. [🏴‍☠️보물찾기 게임 (p02)](src/p02)
*   **개요**: 5x5 크기의 2차원 지도에 무작위로 숨겨진 보물의 좌표를 예측하여 찾아내는 미니 게임입니다.
*   **학습 개념**: 2차원 배열, `Random` 클래스를 이용한 난수 생성, 무한 루프 및 조건문

### 3. [🎹자바 미니 피아노 (p03)](src/p03)
*   **개요**: 숫자 키를 입력하여 개별 음계(`.wav`)를 재생하거나, 배열에 저장된 지정 멜로디를 자동 연주하는 프로그램입니다.
*   **학습 개념**: `javax.sound.sampled` 라이브러리를 이용한 오디오 제어, `Thread.sleep()`을 활용한 실행 지연 (최상위 `sounds/` 디렉토리 참조[cite: 2])

### 4. [🤨미니 MBTI 검사기 (p04)](src/p04)
*   **개요**: 랜덤하게 제시되는 12개의 질문에 대해 1~5점 척도로 응답하면, 이를 누적 연산하여 최종 4자리 MBTI 유형을 도출합니다.
*   **학습 개념**: 역할에 따른 클래스 분리(데이터, 매니저, 메인 로직), 배열 인덱스 셔플 알고리즘
