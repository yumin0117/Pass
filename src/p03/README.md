# 🎹 자바 미니 피아노 (Java Mini Piano)

사용자의 숫자 입력에 따라 실제 오디오 파일(`.wav`)을 재생하여 피아노 소리를 내는 콘솔 기반 프로그램입니다. `javax.sound.sampled` 라이브러리를 활용하여 개별 음계 연주 및 지정된 멜로디 자동 연주 기능을 제공합니다.

## 📂 구조 및 요구사항

- **`MiniPiano.java`**: 오디오 파일 로드 및 재생 로직, 음계 매핑, 자동 연주 스레드 제어(`Thread.sleep`)를 담당하는 단일 메인 클래스입니다.
- **`sounds/` 디렉토리**: 오디오를 정상적으로 재생하기 위해서는 프로젝트 루트 경로에 `sounds` 폴더가 존재해야 하며[cite: 1], 폴더 내부에 `do.wav`부터 `si.wav`까지의 음원 파일이 포함되어 있어야 합니다.

## ✨ 주요 기능

1. **수동 건반 연주**: 숫자 `1` ~ `7`을 입력하면 각각 '도' ~ '시'에 해당하는 오디오 파일을 재생하고 화면에 음계를 출력합니다.
2. **자동 멜로디 연주**: 숫자 `9`를 입력하면 배열에 사전 정의된 멜로디(학교종이땡땡땡)를 0.5초 간격으로 자동 재생합니다.
3. **오류 제어**: 존재하지 않는 파일 경로를 호출하거나 지정되지 않은 번호를 입력할 경우 안전하게 예외 메시지를 띄우고 다음 입력을 대기합니다.
4. **종료**: `0`을 입력하면 자원(`Scanner`)을 반환하고 프로그램을 종료합니다.
