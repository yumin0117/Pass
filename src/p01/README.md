# 음료 자판기 (Vending Machine)

사용자로부터 금액을 입력받고 원하는 음료를 선택하면 거스름돈과 함께 결과를 출력해 주는 간단한 콘솔 기반의 자판기 Java 프로그램입니다. 객체 지향 프로그래밍(OOP)의 상속과 추상화 개념을 활용하여 구현되었습니다.

## 📂 파일 구조

- **`Drink.java`**: 프로그램의 실행 진입점(`main` 메서드)을 포함하는 메인 클래스입니다. 사용자로부터 투입 금액과 음료 번호를 입력받고 결과를 처리합니다.
- **`Run.java`**: 자판기 동작의 기본 틀을 제공하는 추상(Abstract) 클래스입니다. 음료 이름, 가격, 투입 금액, 거스름돈 데이터를 상태로 가집니다.
- **`VendingMachine.java`**: `Run` 추상 클래스를 상속받아 구현된 클래스입니다. `drink()` 메서드를 오버라이딩하여 최종 실행 결과를 화면에 출력합니다.

## ✨ 주요 기능

1. **금액 투입**: 자판기에 넣을 금액을 정수로 입력받습니다.
2. **음료 선택**: 5가지 음료(데미소당, 뚠딴지뽀내나맛유우, 파뤌에이두, 퐌타, 갈지않은배) 중 하나를 선택합니다.
3. **거스름돈 계산 및 출력**: 선택한 음료의 가격을 차감한 거스름돈을 계산하고, 구매 내역을 함께 출력합니다.
4. **예외 처리**: 1~5 이외의 숫자를 입력할 경우 다시 선택하도록 안내합니다.
