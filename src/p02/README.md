# 보물찾기 게임 (Treasure Hunt)

5x5 크기의 지도에 무작위로 숨겨진 보물의 위치를 추측하여 찾아내는 콘솔 기반 미니 게임입니다. Java의 `Random` 클래스를 활용하여 매 실행 시 보물의 위치가 새롭게 바뀝니다.

## 📂 파일 구조

- **`treasure_hunt.java`**: 보물찾기 게임의 전체 로직이 구현된 단일 클래스 파일입니다. 맵 생성, 사용자 입력 처리, 결과 판별 및 맵 상태 업데이트를 모두 수행합니다.

## ✨ 주요 기능

1. **랜덤 보물 배치**: 5x5 크기의 2차원 배열(`map`) 내에 무작위 좌표(행, 열)를 지정하여 보물(값: 1)을 숨깁니다.
2. **현재 맵 상태 시각화**: 
   - 탐색하지 않은 땅은 `?`로 표시됩니다.
   - 이미 파보았으나 보물이 없는 땅(꽝)은 `X`로 표시됩니다.
3. **좌표 탐색 및 결과 판별**: 사용자에게 파볼 땅의 행과 열(1~5)을 입력받아 다음 세 가지 중 하나의 결과를 출력합니다.
   - **보물 발견**: 게임 승리 메시지 출력 후 종료
   - **꽝**: `X` 표시 처리 후 재시도 안내
   - **중복 탐색**: 이미 판 땅임을 알림
4. **유효성 검사**: 맵 크기(1~5)를 벗어난 숫자를 입력할 경우 오류 메시지를 띄우고 다시 입력받습니다.
