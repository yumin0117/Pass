# 미니 MBTI 검사기 (Mini MBTI Test)

사용자에게 12개의 질문을 무작위 순서로 제시하고, 1점부터 5점까지의 응답 점수를 합산하여 최종 성격 유형(MBTI)을 판별해 주는 콘솔 기반 Java 프로그램입니다. 객체 지향 프로그래밍(OOP) 원칙에 따라 데이터, 채점 로직, 테스트 진행 흐름을 각각의 클래스로 분리하여 구현했습니다.

## 📂 파일 구조

`p04` 패키지는 역할에 따라 4개의 파일로 세분화되어 있습니다.

- **`Main.java`**: 프로그램의 실행 진입점입니다. `MbtiTest` 객체를 생성하고 테스트를 시작합니다.
- **`MbtiTest.java`**: 검사의 전체적인 흐름을 제어하는 메인 컨트롤러입니다. 질문 순서를 무작위로 섞고(`shuffleOrder`), 사용자 입력을 받으며, 채점 및 최종 결과 출력을 담당합니다.
- **`QuestionData.java`**: MBTI 4가지 지표(E/I, S/N, T/F, J/P)를 판별하기 위한 12개의 질문 데이터와 선택지 텍스트를 보관하는 데이터 클래스입니다.
- **`ScoreManager.java`**: 사용자의 응답 점수를 지표별로 누적하고, 특정 기준 점수(9점 초과 여부)에 따라 최종 4자리 MBTI 유형(예: ESTJ, INFP 등)을 계산하여 반환합니다.

## ✨ 주요 기능

1. **질문 랜덤 셔플**: 테스트를 시작할 때마다 배열의 인덱스를 섞어 12개의 질문이 매번 다른 순서로 출제됩니다.
2. **5점 척도 응답**: [ 1.매우 아니다 ~ 5.매우 그렇다 ]의 5단계로 답변을 입력받습니다.
3. **자동 결과 도출**: 4가지 지표별로 3개씩 배정된 질문의 점수를 합산하여 최종 성격 유형을 계산합니다.
4. **입력 유효성 검사**: 답변 입력 시 1~5 사이의 숫자가 아니면 경고 메시지를 띄우고 올바른 값을 넣을 때까지 다시 입력받습니다.
